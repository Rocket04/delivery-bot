# Чек-лист запуска в бой (перед Stage 6 / перед реальными заказами)

Всё ниже — продуктовая подготовка, которую делает владелец (или вместе с ботом на стадии 6).

## 1. Меню и каталог
- [ ] Реальные позиции и **реальные цены** (сейчас в базе — плейсхолдеры из сида) — через `/admin`
- [ ] **Фото блюд** добавлены в карточки (`🖼 Фото` у товара) — конверсия сильно зависит от фото
- [ ] Описания внятные: состав, вес (порция/100 г/шт), подводки «на компанию»
- [ ] Порядок категорий и товаров — как в реальном меню (⬆️⬇️)
- [ ] Скрыты позиции, которых сейчас нет (стоп-лист)

## 2. Бизнес-параметры (`.env`)
- [ ] `MIN_ORDER_AMOUNT=20000` — соответствует реальному минимуму
- [ ] `LARGE_ORDER_THRESHOLD=60000` — уточнить: заказ от какой суммы «крупный» (24 ч на закупку)
- [ ] `PREPAY_PERCENT=50` — предоплата
- [ ] `WORK_START_HOUR` / `WORK_END_HOUR` — реальные часы
- [ ] `ADMIN_IDS` — все, кому нужна админка
- [ ] `OPERATOR_CHAT_ID` — группа операторов, бот состоит в ней

## 3. Kaspi-оплата
- [ ] Проверить реальным переводом 1 ₸: номер Kaspi / ссылка на бизнес-счёт / удалённая оплата
- [ ] Отработать сценарий «клиент прислал фейковый чек» → ❌ Чек отклонён → клиент шлёт новый
- [ ] Решить, что видит оператор в реквизитах (сейчас — что вписал оператор при подтверждении)

## 4. Полный прогон (с двух аккаунтов!)
- [ ] Заказ с доставкой: мин. заказ → время (обычный предзаказ ≥ 2 ч) → сводка → подтверждение оператором → предоплата → чек → статусы до «Доставлен»
- [ ] Заказ самовывозом (без адреса)
- [ ] Крупный заказ «на сегодня» — отклоняется, «на завтра» — проходит (24 ч)
- [ ] Ошибки: время 09:00, прошедшее время, корзина меньше 20 000 ₸
- [ ] Отмена оператором с причиной — клиент видит причину
- [ ] «Мои заказы» — история и детали

## 5. Операторы
- [ ] Люди, кто будет оператором, получили доступ к группе и понимают кнопки
- [ ] Инструкция: подтверждение → цена доставки → способ Kaspi → реквизиты → следить за чеками
- [ ] План на случай «клиент не оплатил» (напоминание/отмена с причиной)

## 6. Перед боевым днём
- [ ] Бэкап БД включён (Stage 6: pg_dump по cron)
- [ ] Бот поднят на сервере 24/7 (Stage 6)
- [ ] Логи доступны (логи админке — уже есть: ошибки приходят в личку)
- [ ] Резервный способ заказа на случай падения бота (телефон в «О нас»?) — решить владельцу
